Movies Coming Soon — for kids

Seven takes on the same app: upcoming G and PG movies only, sorted by release date, with favorites, search, posters and trailers. Every one is built for an iPad mini and for a reader who is still learning — big words, read‑aloud, no tiny text. They all work — tap around inside them. Pick the one you like best and that’s the one we build.

Where the real data comes from Every design uses the same plan: TMDB, which is free for non‑commercial apps and is the only free source that covers all four things we need. Upcoming films filtered to kid ratings via /discover/movie?certification_country=US&certification.lte=PG, posters from image.tmdb.org, and YouTube trailer keys from /movie/{id}/videos. Attribution to TMDB is required.

Titles and poster art in these prototypes are made‑up placeholders so nothing here uses copyrighted artwork — the real app swaps in live TMDB data.
